# 数字人技术视图

数字人技术视图用于保留和展示 OneLive 已有的程序化人脸、口型、姿态及网络退化能力，不是 2–3 分钟领导演示的默认主线。

## 打开方式

1. 打开右上角“网络设置”。
2. 在“演示视图”中选择“数字人技术视图”。
3. 需要返回主演示时，重新选择“视频样例”。

开始或推进六步导演流程时，系统会自动回到“视频样例”，避免技术预览干扰“原视频 → 三地区本地化视频”的叙事。

## 能力边界

- 三个地区的数字人、人脸、口型和姿态均为程序化模拟，界面标记为 `EMULATED`。
- 网络拥塞、弱网、高时延、Edge 与 QoD 会继续改变数字人频道的画面状态与指标。
- 当前视图不代表真实人脸替换、声音克隆或实时生成链路已经接通。
- WebGL 不可用时自动使用 2D 安全渲染；默认视频演示不依赖 WebGL。

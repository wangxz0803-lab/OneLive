# OneLive ViewLab 未来体验界面设计规范

> 状态：设计定稿，不代表已实现。
> 目标画布：1440 × 900。
> 适用场景：比赛现场展示“自由视角”和“空间直播”的未来观看方式。

## 1. 定稿画面

- [自由视角](./free-view-final.png)
- [空间直播](./spatial-live-final.png)

两张图属于同一套界面系统。它们定义视觉层级、控件位置、文案和状态，不证明当前 Demo 已具备同步多机位生成、连续自由视角或实时三维重建能力。

## 2. 设计目标

评委进入 ViewLab 后，应当先看到新的观看方式，再理解它的实现条件：

1. 自由视角：同一直播时刻可以在正面、侧面和俯拍之间选择。
2. 空间直播：观众可以改变观察位置，查看场景纵深和商品角度。
3. 能力边界：界面始终说明当前是素材驱动的视觉概念。

本界面不承担网络、QoD、带宽或部署架构的解释。这些信息留在主 Demo，避免未来体验再次变成指标控制台。

## 3. 全局结构

### 3.1 1440 × 900 基准布局

| 区域 | 建议规格 | 作用 |
| --- | --- | --- |
| 页面安全边距 | 左右 20px，上下 18px | 保证比赛投屏不贴边 |
| 顶栏 | 56–64px | 品牌、模式切换、能力标签、关闭 |
| 主体验区 | 约 1070px 宽 | 主画面和当前模式交互 |
| 说明栏 | 约 310px 宽 | 当前状态、观看收益、实现条件 |
| 主区与说明栏间距 | 14–16px | 保持整体连续，不形成两套页面 |
| 圆角 | 12–16px | 仅用于主容器和主要按钮 |

1440 × 900 下不出现页面级滚动。1920 × 1080 下按比例增加外部留白，主内容保持合理最大宽度，不横向拉伸人物。

### 3.2 视觉系统

| 用途 | 颜色 |
| --- | --- |
| 页面背景 | `#05070B` |
| 主表面 | `#0C121A` |
| 次级表面 | `#111925` |
| 选中与交互 | `#54DCE7` |
| 主文字 | `#F4F7FA` |
| 次文字 | `#9AA8B6` |
| 不可用提示 | 低饱和琥珀，仅在确有缺失时使用 |

禁止使用紫色霓虹、装饰性全息人物、巨型指标、无意义光效和卡片墙。空间点云属于内容资产，不作为整个页面的装饰背景。

### 3.3 顶栏

固定元素：

- `OneLive ViewLab`
- `自由视角`
- `空间直播`
- 能力标签
- `关闭`

能力标签随模式变化：

- 自由视角：`概念设计 · 素材驱动`
- 空间直播：`概念设计 · 空间资产驱动`

标签在任何状态下都保持可见，不能被隐藏到帮助面板中。

## 4. 自由视角状态

### 4.1 信息层级

1. 主舞台：展示当前机位的完整 16:9 画面。
2. 弧形机位轨道：显示三个离散、语义明确的机位。
3. 同步视角时间轴：表达三路素材共享同一个 15 秒叙事周期。
4. 右侧说明：只解释当前机位的观看价值和真实依赖。

### 4.2 三个机位

| 机位 | 主要内容 | 观看价值 |
| --- | --- | --- |
| 正面主播 | 人物、表情、手势与完整商品 | 聚焦人物表达与商品关系 |
| 侧面互动 | 主播侧面、台面深度与横向视差 | 呈现互动动作与空间关系 |
| 俯拍商品 | 锅具、双手和操作区域 | 呈现商品细节与操作过程 |

三个机位必须提供新的观察信息，不能由同一张竖屏画面简单裁切获得。

### 4.3 交互状态

| 状态 | 设计表现 | 行为约束 |
| --- | --- | --- |
| 默认 | 正面主播选中 | 首次进入不自动轮播 |
| 悬停 | 机位名称和说明提亮 | 不触发画面切换 |
| 选中 | 青色定位环、相机图标和连接线 | 主画面切换至对应机位 |
| 素材加载中 | 主画面保留上一帧，机位显示加载状态 | 不显示空白舞台 |
| 素材不可用 | 对应机位不可选，显示“素材未就绪” | 不用裁切图伪装该机位 |

### 4.4 切换规则

- 静态图片方案：240ms 交叉淡化，不使用大幅推拉或3D旋转。
- 同步视频方案：切换机位时保持相同 `currentTime`，不得从零重新播放。
- 时间轴范围固定为 `00:00–00:15`，三个机位的关键动作点保持对齐。
- `切换观看视角`用于确认当前选择并进入观众预览，不承担生成或加载动作。
- 键盘左右方向键可在三个机位间移动，Enter 确认。

### 4.5 右栏文案

当前视角：

```text
正面主播
聚焦人物表达与商品关系
```

观看收益：

```text
完整人物表达
商品与手势同框
保持空间关系
```

实现条件：

```text
同步多机位素材
视角生成模型
多路实时编码
```

## 5. 空间直播状态

### 5.1 信息层级

1. 空间舞台：主体保持真实，环境外缘展示空间重建信息。
2. 观察范围：明确当前可用范围为 `-30° 至 +30°`。
3. 观察锚点：左侧、正面、右侧。
4. 右侧说明：当前观察位置、观看收益和空间资产依赖。

### 5.2 空间画面要求

- 主播、商品和台面中心区域保持照片级真实。
- 场景外缘逐渐显示稀疏深度点、半透明结构或重建边界。
- 点云密度服从空间信息，不覆盖人物脸部和商品主体。
- 不使用旋转的平面视频卡片冒充三维空间。
- 不使用“实时重建中”“LIVE 3D”等无法证明的状态。

### 5.3 交互状态

| 状态 | 设计表现 | 行为约束 |
| --- | --- | --- |
| 默认 | 正面观察，0° | 进入页面后主体处于稳定构图 |
| 左侧观察 | 角度向 -30° 移动 | 仅在对应空间数据存在时启用 |
| 右侧观察 | 角度向 +30° 移动 | 仅在对应空间数据存在时启用 |
| 拖动 | 角度标记跟随指针 | 真空间资产下才允许连续变化 |
| 重置 | 返回 0° | 不重新加载空间资产 |
| 覆盖不足 | 不可观看区降低亮度并停止拖动 | 明确显示“空间数据未覆盖” |

### 5.4 三档能力降级

| 素材条件 | 界面允许的交互 | 必须显示的标签 |
| --- | --- | --- |
| 只有静态概念图 | 三个预设画面离散切换 | `视觉概念 · 预设视角` |
| 有三路同步视频 | 三个锚点视角切换 | `素材驱动 · 非连续视角` |
| 有3DGS/NeRF/网格资产 | 在已覆盖范围内连续拖动 | `空间资产驱动` |

前两档不得开放连续角度滑杆。如果为了讲解保留滑杆外观，拖动后必须吸附到三个锚点，并标注为预设视角。

### 5.5 右栏文案

当前空间状态：

```text
正面观察 · 0°
从固定画面进入可选择的观察位置
```

观看收益：

```text
观察场景纵深
改变商品观察角度
保留人物与空间关系
```

实现条件：

```text
多机位或深度采集
3DGS或NeRF空间资产
WebGL实时渲染
```

## 6. 动效规范

| 动效 | 时长 | 说明 |
| --- | --- | --- |
| 模式切换 | 240–320ms | 主画面淡出、结构变化、内容淡入 |
| 离散机位切换 | 200–260ms | 交叉淡化，保持同步时间点 |
| 机位轨道选中 | 160–220ms | 定位环、连接线和文字同步变化 |
| 空间拖动 | 跟手 | 只在真实空间资产存在时启用 |
| 重置视角 | 280–360ms | 平滑回到 0°，不使用弹性过冲 |

`prefers-reduced-motion` 下取消推镜、视差和扫描效果，只保留即时状态变化与短淡化。

## 7. 素材清单

### 7.1 A档：静态概念演示

最低素材：

- `front.png`：1920 × 1080 正面机位。
- `side.png`：1920 × 1080 35°侧面机位。
- `overhead.png`：1920 × 1080 俯拍商品机位。
- `spatial-key-visual.png`：1920 × 1080 空间重建概念图。

可以实现：界面展示、离散图片切换、空间模式静态说明。
不能实现：同步运动、连续视角、真实遮挡关系。

### 7.2 B档：同步多视角演示

每个机位一段视频：

- 1920 × 1080。
- 30fps。
- 15秒。
- H.264。
- 无音轨，由主节目音频统一播放。
- 首帧、动作峰值和尾帧严格对齐。
- 固定摄像机，无切镜、无推拉、无变焦。

生成后重点检查：人脸、双手、锅具尺寸、把手、电源线、服装和背景几何连续性。

为降低浏览器解码压力，可将三路横向拼接为一个 `2880 × 540` atlas 视频，再从单个解码时间轴裁出三个机位。

### 7.3 C档：真实空间演示

至少需要：

- 同步多机位视频或深度采集数据。
- 相机内参、外参和统一时间戳。
- 3DGS、NeRF、点云或带纹理网格资产。
- 已定义的可观察范围和不可见区域。
- WebGL/WebGPU 渲染器。
- 动态人物重建或提前录制的空间序列。

单张图片或三段普通视频无法推导真实的连续自由视角，也无法正确补全人物背面、锅具遮挡区域和场景深度。

## 8. 当前不能直接承诺的效果

- 从单路主播视频实时生成任意角度画面。
- 连续旋转视角时保持人脸、手指和商品绝对一致。
- 实时动态3DGS/NeRF重建并在普通手机浏览器稳定运行。
- 在没有相机标定和空间资产时得到真实视差和遮挡。
- 仅靠CSS平移、缩放或旋转实现可信的三维观看。

这些能力可以作为未来路线呈现，但在演示中必须使用“概念”“素材驱动”或“空间资产驱动”等准确标签。

## 9. 验收标准

- 评委不阅读说明也能区分自由视角和空间直播。
- 主画面始终是视觉中心，右栏不抢占注意力。
- 三个机位提供不同观察信息，不是同图裁切。
- 两个模式都持续显示能力边界。
- 1440 × 900 首屏完整，无横向或纵向页面滚动。
- 未准备的素材表现为不可用状态，不使用近似效果伪装。
- 页面不展示Edge、QoD、网络指标或与未来观看无关的信息。
- 当前设计稿与后续实现逐项对照，不能因为实现困难擅自降低语义。

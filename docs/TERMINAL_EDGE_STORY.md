# OneLive端侧AI直播故事

## 核心场景

OneLive的目标形态不是用预制数字人替代主播，而是让一位真人主播通过一台端侧AI直播终端，同时生成日语、西班牙语和英语三路本地化直播。

当前Demo使用四段预录视频展示目标效果；AI生成、网络参数、Edge和QoD均为 `EMULATED`，不能宣称已经实现生产级实时转换。

## 两种拓扑

云端生成：

`真人主直播源 → 单路源流上行 → 云端AI生成 → 三路内容分发 → 三个市场`

端侧生成：

`真人主直播源 → 端侧AI直播终端 → 三路并发上行 → 5G/QoD承载 → 三个市场`

只有端侧生成拓扑会在主播侧形成三路并发上行。不要把运营商MEC、中心云和端侧AI终端混为同一个位置。

## 网络与商业价值

- 端侧AI缩短翻译、音色和口型处理路径，但不会增加物理带宽。
- 三路直播共享有限上行资源，拥塞、抖动和丢包会直接影响市场交付。
- QoD按优先级分配有限资源，不把所有频道无条件调成最佳质量。
- 商家获得一位真人覆盖多个市场的能力；运营商可组合AI终端、5G上行、QoD和本地化软件服务。

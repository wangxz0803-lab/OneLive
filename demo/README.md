# OneLive 演示台（B 路线：预生成数字人 + 可操作前端）

双击 `index.html` 即可打开，**不需要启动任何服务**，断网也能演示。

---

## 现场怎么演（建议动线）

| # | 动作 | 评委看到什么 |
|---|------|--------------|
| 1 | 点手机上的 **「开始直播」** | 手机进入 LIVE → 三路数字人依次上线 → 底部链路逐段点亮 → 五个平台开始推流 |
| 2 | 点右侧 **网络条件** 里的「拥塞 / 弱覆盖」 | 上行画面**真的变糊变卡**、码率/延迟/丢包同步变化、推流分辨率自动从 1080P 降到 480P、数据增长变慢 |
| 3 | 切回 **「优秀」** | 画面立刻恢复清晰，指标回升 |
| 4 | 点某一路的 **「换形象」** | 该频道数字人与场景整体切换 |
| 5 | 点 **推流平台** 某一行 | 该平台上下线，顶栏推流数跟着变 |
| 6 | 点 **「结束直播」** | 全部下播，可重复演示 |

> 第 2 步是最有说服力的一环：画面劣化是**逐帧实时计算**的（按丢包率丢帧、按带宽降采样再放大、按抖动值延迟绘制），不是播放预设动画。

## 换成你自己的数字人素材

把文件丢进 `assets/` **覆盖同名文件**即可，无需改代码、无需运行脚本：

| 文件 | 用途 | 规格建议 |
|------|------|----------|
| `ch1.mp4` | English 频道 | 竖屏 **540×640**（或同比例，如 1080×1280），12–30 秒，**能循环**（首尾姿态接近） |
| `ch2.mp4` | 日本語 频道 | 同上 |
| `ch3.mp4` | Español 频道 | 同上 |
| `host.mp4` | 手机端 / 原始主播画面 | 竖屏 **540×700** 同比例 |
| `poster1~3.png` | 各频道封面（视频没加载时兜底） | 与对应视频同比例 |
| `poster-host.png` | 主播封面 | 同 `host.mp4` 比例 |

编码用 **H.264 / MP4**，无需音轨（页面静音播放）。分辨率给大一些没问题，浏览器会自适应。

**生成平台推荐**：HeyGen（质量最好、多语言口播）、即梦 / 可灵 Kling、硅基智能 / 腾讯智影。

尺寸不对也能用（`object-fit: cover` 会自动裁切），但比例接近效果最好。

当前 `assets/` 里是**占位视频**（由形象图加缓慢运镜生成），换成真素材后演示效果会有质的提升。

## 诚实边界（页脚已写明，评委问起来站得住）

- **预生成**：数字人形象视频为提前生成的素材，不是现场实时渲染
- **演示值**：观看数 / 点赞 / 评论 / 分享为演示数据
- **真实计算**：网络劣化对画面的影响是实时计算的，不是预录动画
- 项目另有**真实可运行**的部分（引擎、真实 RTMP 推流、双端网络遥测、手机 App），见仓库根目录与 `engine/run-demo.ps1`

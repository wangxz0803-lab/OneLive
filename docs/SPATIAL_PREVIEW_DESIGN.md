# OneLive Future Experience 设计稿（V1，已由 V2 替代）

> 当前实现与素材规范请以 `docs/FUTURE_EXPERIENCE_V2.md` 为准。本文件保留用于追踪第一版设计取舍。

## 1. 设计目标

在现有多语言直播 Demo 完成后，增加一个独立的未来体验入口，用于表达两层设想：

1. 多语言直播可以继续扩展为多语言、多视图直播。
2. 多视图进一步发展后，可以进入自由视点和空间直播形态。

这部分用于解释未来网络需求，不改变现有六步主演示，也不把概念预演包装成已经完成的生产能力。

## 2. 产品定位

### 名称

界面名称：`OneLive Spatial Preview`

中文名称：`未来体验`

状态标签：`CONCEPT / EMULATED`

### 一句话叙事

> 从一种内容的多语言交付，扩展到同一现场的多语言、多视图和空间化交付。

### 与当前 Demo 的关系

- 当前六步是可操作的核心演示。
- Future Experience 是可选的第七步，只在核心演示完成后打开。
- 关闭 Future Experience 后，原有直播状态、网络档位、QoD 状态和 PROGRAM 选择全部保留。
- Future Experience 不进入 Director 主状态机，不改变现有快捷键语义。

## 3. 设计原则

### 保留

- 深色演播室主题。
- Graphite 面板、蓝色网络状态、紫色空间计算提示、红色退化告警。
- 现有 12-16px 圆角体系。
- PROGRAM 舞台仍然是视觉主体。
- 当前视频继续播放，不重新加载，不打断声音。

### 新增

- 顶栏增加一个次级按钮：`未来体验`。
- 点击后打开覆盖控制台的沉浸式概念层。
- 概念层内提供 `多视图` 和 `空间直播` 两个模式。
- 多视图模式提供可操作的流量倍增和按需视口对比。
- 空间直播模式提供可拖动的空间视角预演，但不宣称真实三维重建。

### 不做

- 不增加第七个主流程状态。
- 不接入真实 NeRF、Gaussian Splatting、点云或深度相机。
- 不编造 3D 模式的固定码率和生产 SLA。
- 不把同一视频的裁切画面称为真实多机位。
- 不让概念层覆盖 LIVE / EMULATED 的能力边界。

## 6. 多视图模式

### 视觉表现

使用当前 PROGRAM 的真实视频时间轴生成三种同步构图：

1. `主播跟随`：保持当前完整竖屏构图。
2. `商品特写`：裁切并放大商品和手部区域。
3. `互动近景`：裁切并放大主播面部和上半身。

必须在界面底部说明：`当前为同源智能裁切预演，不代表真实多机位采集`。

这三种构图称为多视图，不称为多机位。真实多机位能力在未来路线中单独说明。

### 交互

- 点击任一视图，将它切到主舞台。
- 切换只改变裁切参数，不改变视频 `currentTime`。
- 三个缩略视图持续同步播放。
- 切换动画为 220ms 的 opacity 和 transform 过渡。
- `prefers-reduced-motion` 下立即切换。

### 网络模型

基准来自当前 Demo 的真实账本：

- 三语言单视图目标需求：`18.48 Mbps`。
- 三语言三视图全量传输：`18.48 × 3 = 55.44 Mbps`。
- Edge 按需视口：每个市场只交付当前视图，需求回到 `18.48 Mbps`。
- 如果沿用当前 15 Mbps QoD 保障，继续显示两路 VIP 1080P 和一路 Best Effort 480P。

右侧提供一个策略切换：

- `全量视图`：显示 9 路和 55.44 Mbps，状态为严重超出预算。
- `按需视口`：显示 3 路和 18.48 Mbps，说明 Edge 只渲染和交付当前选择。

这些数字必须标记为 `EMULATED`，因为并未真实编码九路视频。

## 7. 空间直播模式

### 视觉表现

- 中心保留当前 PROGRAM 画面。
- 画面置于有轻微透视的空间舞台中。
- 用户水平拖动可改变观察角度，范围限制在 -28° 到 +28°。
- 舞台周围显示三个采集方向，不显示虚构摄像机型号。
- 拖动只改变预演画面的 CSS 透视和视口位置。

### 文案

标题：`自由视点与空间直播`

说明：

> 未来可由多机位或深度采集构建空间资产，并在 Edge 侧完成重建、渲染和按视口交付。

状态说明：

`二维母版空间映射 / 非实时三维重建`

### 数据边界

- 不显示固定 3D 码率。
- 负载显示为 `场景相关`。
- 网络策略显示为 `按视口自适应`。
- QoD 作用对象显示为 `当前视口 + 音频 + 交互控制`。
- 网络定位只用于选择更近的 Edge 节点和区域预取，不宣称它能生成 3D 内容。

## 8. 右侧解释区

右侧固定包含三个内容组。

### 内容规模

多视图状态：

```text
3 语言 × 3 视图
9 路内容
```

空间直播状态：

```text
自由视点
负载随场景变化
```

### 交付策略

多视图状态：

- 全量视图：所有视图同时编码和交付。
- 按需视口：只交付用户当前选择。

空间直播状态：

- Edge 侧重建和渲染。
- 视口自适应下发。
- 当前视口优先。

### 网络能力

流程：

```text
多源采集 > Edge 时空对齐 / 渲染 > 当前视口 > 5G / QoD
```

能力说明：

- Edge 降低交互路径，并避免全量视图持续回传。
- QoD 保障当前视口、核心音频和交互控制。
- 网络定位选择更近的 Edge 节点，可作为未来能力说明。

## 9. 状态与标签

### 允许使用

- `CONCEPT`
- `EMULATED`
- `预生成同步母版`
- `同源裁切预演`
- `二维母版空间映射`
- `非实时三维重建`

### 禁止使用

- `LIVE 3D`
- `实时 NeRF`
- `真实多机位`
- `运营商 MEC 已部署`
- `网络定位已接入`
- `生产 QoD SLA`

## 10. 视觉规范

### 色彩

- 背景：沿用 `#050710` 和 `#01030A`。
- 文本：沿用 `#F2F6FF`、`#9AAAC6`、`#5F6E8A`。
- 交互主色：沿用网络蓝 `#5B9DFF`。
- 空间模式强调色：使用现有紫色 `#8F72FF`，只用于空间计算和视角状态。
- 红橙色只用于容量不足和降级。

### 形状

- 概念层：16px 圆角。
- 内部面板：12px 圆角。
- 按钮保持现有控制台规格，不增加大面积胶囊标签。

### 字体

- 沿用当前内联字体。
- 数字继续使用等宽数字样式。
- 不新增外部字体和网络依赖。

### 动效

- 概念层打开：260ms opacity + scale，从 0.985 到 1。
- 视图切换：220ms opacity + transform。
- 空间拖动：直接跟随指针，不写入 React 状态。
- 关闭：180ms opacity。
- 所有动效支持 reduced motion。

每个动效的理由：

- 打开和关闭用于说明层级变化。
- 视图切换用于说明当前视口变化。
- 空间拖动用于提供交互反馈。

不增加无意义的持续漂浮、粒子和无限发光动画。

## 11. 键盘与可访问性

- `V`：打开或关闭 Future Experience。
- `Esc`：关闭概念层。
- Tab 顺序：关闭按钮 > 模式切换 > 视图选择 > 分发策略。
- 弹层打开时焦点进入关闭按钮。
- 弹层关闭后焦点回到未来体验按钮。
- 弹层使用 `role="dialog"`、`aria-modal="true"` 和可访问标题。
- 三个视图选择按钮至少为 44 × 44 CSS px。
- 不依赖颜色区分选中、告警和概念状态。

## 12. 响应式规则

### 1440 × 900

- 整个概念层完整进入首屏。
- 左右双栏，不产生页面滚动。
- 主舞台保持主导地位。

### 1920 × 1080

- 概念层最大宽度 1760px。
- 不无限放大文本和控件。

### 小于 900px

- 概念层允许内部纵向滚动。
- 改为单列：主舞台 > 视图选择 > 网络解释。
- 空间拖动仍可用触摸操作。

## 13. 演示脚本

核心六步结束后：

1. 点击 `未来体验`。
2. 说明当前是一场直播、三个语言市场和一个视图。
3. 进入多视图预演，展示主播跟随、商品特写和互动近景。
4. 切换到 `全量视图`，显示 3语言 × 3视图 = 9路、55.44 Mbps。
5. 切到 `按需视口`，说明 Edge 只生成和交付当前视口，需求回到三路。
6. 切换到 `空间直播`，拖动画面展示自由视点交互设想。
7. 指出 3D 为概念预演，未来可由多机位或深度采集替换当前二维母版。

建议话术：

> 今天我们展示的是一位主播同时面向三个语言市场。下一步，同一场直播还可以提供主播跟随、商品特写和互动近景。此时内容规模会从三路变成九路，网络需求按语言和视图相乘。Edge 可以在靠近用户的位置完成视图渲染，只交付当前视口；QoD 继续保障当前视口、核心音频和交互控制。再向前一步，就是自由视点和空间直播。当前展示的是概念预演，不是实时三维重建。

## 14. 验收标准

### 主链路

- 原有六步测试全部通过。
- 不打开 Future Experience 时，现有页面视觉和交互不变。
- 打开和关闭后，直播媒体不暂停、不重新加载。

### 多视图

- 三个视图使用同一媒体时间轴。
- 点击视图后主舞台在 300ms 内完成切换。
- 全量视图显示 9 路和 55.44 Mbps。
- 按需视口显示 3 路和 18.48 Mbps。

### 空间直播

- 水平拖动可改变观察角度。
- 角度限制在 -28° 到 +28°。
- 页面明确显示非实时三维重建。
- 不显示虚构固定码率。

### 视觉与可访问性

- 1440 × 900 无页面横向或纵向溢出。
- 1920 × 1080 无布局重叠。
- 390 × 844 无横向溢出。
- Esc、V、Tab 和焦点返回行为正确。
- reduced motion 下内容仍完整可读。

## 15. 实现顺序

1. 新增 Future Experience 入口和弹层骨架。
2. 复用当前 PROGRAM 媒体源，完成三个同步裁切视图。

4. 完成空间视角拖动预演。
5. 增加能力边界标签、快捷键和焦点管理。
6. 更新 README、DECISIONS 和 Playwright 测试。

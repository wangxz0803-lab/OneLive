# OneLive Demo Media

The UI expects these stable filenames:

- `original-zh.mp4` — original Chinese 15-second recording.
- `japan-ja.mp4` — Japanese localized output.
- `latam-es.mp4` — LATAM Spanish localized output.
- `india-en.mp4` — India English localized output.

The original, Japan, and LATAM assets were copied from the approved local demo sources on 2026-08-09. The final India render was supplied and added on 2026-08-10. If any localized asset is unavailable, the UI falls back to the original recording and labels that state explicitly; it never presents fallback media as a completed localized asset.
